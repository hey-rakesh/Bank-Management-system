# 🏦 Bank Management System

A modular **Bank Management System** built with **Python**, **MySQL**, and **Object-Oriented Programming (OOP)**. 
It enables users to manage customers, bank accounts, and transactions through a command-line interface.

---

## ✨ Features

- 👤 Customer Management
- 🏦 Savings & Current Accounts
- 💰 Deposit & Withdraw Money
- 🔄 Fund Transfer
- 📜 Transaction History
- 🛡️ Input Validation & Exception Handling

---

## 🛠️ Tech Stack

- Python
- MySQL
- Object-Oriented Programming (OOP)
- mysql-connector-python

## 🚀 Installation

```bash
git clone https://github.com/your-username/Bank-Management-System.git

cd Bank-Management-System

pip install -r requirements.txt
```

Configure your MySQL database credentials and run:

```bash
python main.py
```
